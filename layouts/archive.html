Damit stehen die Reisetage zweimal in der Leiste — unter PHOTO als Bild, unter TRIP als Reise. Die fünf Zahlen addieren sich deshalb nicht mehr auf ALL, und das ist Absicht: TRIP ist die engere Frage, nicht der Rest von PHOTO. Das zweite `where` auf cover ist kein Zierrat: `!= nil` trifft auch den leeren String. */}} {{ if eq $stream "photos" }} {{ $trips := where (where (where $posts "Section" "trips") "Params.cover" "!=" nil) "Params.cover" "!=" "" }} {{ $posts = sort (union (where $posts "Section" "photos") $trips) "Date" "desc" }} {{ else if ne $stream "all" }} {{ $posts = where $posts "Section" $stream }} {{ end }}
