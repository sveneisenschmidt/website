Anthropic released an update to the Claude Code CLI and the Claude desktop app, both have proper file explorers and sticky diffs now. Which is funny because I [wrote a few days ago](/2026-09-10-worktrees/) how to achieve the same with Zed. Might drop Zed then soon.

Did some updates to the website, changed the font to [Hanken Grotesk](https://fonts.google.com/specimen/Hanken+Grotesk) and introduced a clearer separation between labels and links that should improve how easy it is to navigate the website. Also the article header is now fixed on mobile.

I use a lot of worktrees, virtual machines to test Hypo, and Hypo has bugs that leave old cache files behind, so I ran into space problems more often than I liked. [Radix](https://tryradix.app) was helpful to see where the space went, I freed up a few hundred gigabytes that way, more than once. It is [open source](https://github.com/colinvkim/Radix), installs with `brew install --cask radix`, and it does not carry the enshittified bloat of DaisyDisk. It also brings me to the idea of making Hypo installable with brew, and introducing auto updates along with it.
