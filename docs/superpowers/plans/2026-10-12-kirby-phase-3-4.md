# Umzug von Hugo auf Kirby: Phase 3 (Templates) und Phase 4 (URLs)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Ziel:** Kirby zeigt jede Seite so, wie Hugo sie heute baut: Startseite, Beiträge, Archiv, Suche, About, 404, Feed, Sitemap, `robots.txt` und `llms.txt`. Jede heutige URL antwortet unter derselben Adresse oder führt mit 301 weiter.

**Architektur:** Templates und Snippets schreiben das Markup von Hugos `layouts/` nach. CSS und JS aus `assets/` liegen unverändert in `www/assets/`, mit zwei kleinen Änderungen: `search.js` holt die Treffer vom Server, `map.js` zeigt Namen von Kartenpunkten als Text. Ein Page Model gibt jeder Seite Hugos URL mit Schrägstrich am Ende, eine Route vor Kirbys eigenen beantwortet Weiterleitungen, Beiträge und alte Adressen. Die Weiterleitungen sind Inhalt (`content/.redirects.json`), gestartet mit `data/redirects.yaml`, und liefern auch die festen GUIDs des Feeds.

**Technik:** Kirby 5.6.1, PHP 8.5, PHPUnit 12, SmartyPants und Symfony YAML aus Kirbys Abhängigkeiten, SQLite über PDO für den Pop-Import, Apache `.htaccess`.

**Grundlage:** `docs/superpowers/plans/2026-10-12-kirby-umzug.md`, Abschnitte „Gesamtplan“, „Rückbau der Hugo-Notlösungen“ und „Was Phase 2 bis 5 wissen müssen“. Phase 1 und 2 sind fertig. Die Aufgaben zählen dort weiter: 16 bis 30.

- [ ] **Schritt 5: `www/site/plugins/blog/text.php` anlegen**

```php
<?php

use Kirby\Cms\Page;

/**
 * Text as Hugo made it from Markdown: headings with an anchor, the summary,
 * plain text, words and truncation for meta tags and the feed. Each
 * function does what the Hugo function in its comment did.
 */

/** KirbyText, with ids and anchors on headings as layouts/_markup/render-heading.html. */
function blog_html(string $text, Page $page): string
{
    $ids = [];
    return preg_replace_callback('!<h([1-6])>(.*?)</h\1>!s', function (array $m) use (&$ids) {
        $id = blog_anchor(html_entity_decode(strip_tags($m[2]), ENT_QUOTES | ENT_HTML5, 'UTF-8'));
        // Hugo numbers a repeated id: x, x-1, x-2.
        $n = $ids[$id] = isset($ids[$id]) ? $ids[$id] + 1 : 0;
        $id = $n === 0 ? $id : "$id-$n";
        return "<h{$m[1]} id=\"$id\">{$m[2]}<a class=\"heading-anchor\" href=\"#$id\">#</a>\n</h{$m[1]}>";
    }, kirby()->kirbytext($text, ['parent' => $page]));
}

/** Hugo's GitHub-style heading id: letters, digits and "_" in lower case, space and "-" as "-". */
function blog_anchor(string $text): string
{
    $id = '';
    foreach (mb_str_split(trim($text)) as $char) {
        if ($char === ' ' || $char === '-') {
            $id .= '-';
        } elseif ($char === '_' || preg_match('/^[\p{L}\p{N}]$/u', $char)) {
            $id .= mb_strtolower($char);
        }
    }
    return $id;
}

/** Hugo's .Content: intro and text as one Markdown text. */
function blog_content(Page $page): string
{
    return blog_html(trim($page->intro()->value() . "\n\n" . $page->text()->value()), $page);
}

/**
 * Hugo's .Summary: the intro. Without one, as Hugo's automatic summary,
 * the paragraphs of the text until they hold 70 words.
 */
function blog_summary(Page $page): string
{
    if ($page->intro()->isNotEmpty()) {
        return blog_html($page->intro()->value(), $page);
    }
    $summary = '';
    foreach (preg_split('/\n\s*\n/', trim((string)$page->text()->value())) as $block) {
        $summary .= ($summary === '' ? '' : "\n\n") . $block;
        if (blog_words(blog_html($summary, $page)) >= 70) {
            break;
        }
    }
    return blog_html($summary, $page);
}

/**
 * Hugo's plainify: tags out, scripts with their content, a line break for
 * each paragraph, a run of white space as its first character. Entities
 * stay, as in Hugo.
 */
function blog_plain(string $html): string
{
    $html = preg_replace('!<script\b.*?</script>!s', '', $html);
    $html = str_replace(["\n", '</p>', '<br>', '<br />'], [' ', '___hugonl_', '___hugonl_', '___hugonl_'], $html);
    $text = str_replace('___hugonl_', "\n", strip_tags($html));
    return preg_replace('/(\s)\s+/u', '$1', $text);
}

/** Hugo's countwords: the words of the plain text. */
function blog_words(string $html): int
{
    return count(preg_split('/\s+/u', blog_plain($html), -1, PREG_SPLIT_NO_EMPTY));
}

/** Hugo's truncate: at most $length characters, cut after a word, then " …". */
function blog_truncate(string $text, int $length = 160): string
{
    if (mb_strlen($text) <= $length) {
        return $text;
    }
    $cut = mb_substr($text, 0, $length + 1);
    return (preg_match('/^(.*\S)\s/us', $cut, $m) ? $m[1] : mb_substr($text, 0, $length)) . ' …';
}
```

```php
/**
 * The posts and what the templates say about them.

/** The sections that hold posts, as in Hugo. */
const BLOG_SECTIONS = ['photos', 'trips', 'notes', 'essays'];

/** Hugo's [params] from hugo.toml. */
const BLOG_SITE = [
    'description' => 'Personal website of Sven Eisenschmidt, based in Leipzig, Germany.',
    'heading' => 'Sven Eisenschmidt',
    'author' => 'Sven Eisenschmidt',
    'keywords' => 'Sven Eisenschmidt, Leipzig, Germany, video games, music, cycling, travel, software development, photography',
    'jobTitle' => 'Chief Technology & Product Officer',

    'stravaUrl' => 'https://strava.com/athletes/sveneisenschmidt',
    'email' => 'sven.eisenschmidt@gmail.com',

/** All published posts, newest first. Hugo sorted by date, then by title. */
function blog_posts(): Pages
{
    $posts = new Pages([]);
    foreach (BLOG_SECTIONS as $section) {
        if ($parent = page($section)) {
            $posts->add($parent->children()->listed());
        }
    }
    return $posts->sortBy('date', 'desc', 'title', 'asc');
}

/** True for a post (photo, trip, note or essay), also a draft. */
function blog_is_post(Page $page): bool
{
    return in_array($page->parent()?->id(), BLOG_SECTIONS, true) && $page->parent()->parent() === null;
}

/** The picks with a cover, newest first (front.html). */
function blog_picks(): Pages
{
    return blog_posts()->filter(fn (Page $post) => $post->pick()->toBool() && $post->cover()->toFile() !== null);
}

/** "January 2, 2006" */
function blog_date(Page $post): string
{
    return $post->date()->toDate('F j, Y');
}

/**
 * The type line of a post (article-type.html): the day of a trip, the
 * reading time of an essay, else the type. Without $withType, as on the
 * post page, no type word.
 */
function blog_type_line(Page $post, bool $withType = true): string
{
    if ($post->trip()->isNotEmpty()) {
        $trip = $post->trip()->value();
        $days = blog_posts()->filter(fn (Page $p) => $p->trip()->value() === $trip)->sortBy('date', 'asc');
        return sprintf('%s, day %d of %d', ucwords(str_replace('-', ' ', $trip)), $days->indexOf($post) + 1, $days->count());
    }
    return match ($post->intendedTemplate()->name()) {
        // Hugo's .ReadingTime: 213 words a minute, rounded up.
        'essay' => ($withType ? 'Essay, ' : '') . (int)ceil(blog_words(blog_content($post)) / 213) . ' min',
        'note' => $withType ? 'Note' : '',
        'photo' => $withType ? 'Photo' : '',
        default => '',
    };
}

/** True when the text of a post holds the map. */
function blog_has_map(Page $page): bool
{
    return str_contains($page->intro()->value() . $page->text()->value(), '(map:');
}
```

```php
/** Hugo's .Kind: home, page, section (archive and search) or 404. */
function blog_kind(Page $page): string
{
    return match (true) {
        $page->isHomePage() => 'home',
        $page->isErrorPage() => '404',
        in_array($page->id(), ['archive', 'search'], true) => 'section',
        default => 'page',
    };

/** The meta description (head/meta.html): the summary of a post or of About, else the site's. */
function blog_description(Page $page): string
{
    $summary = blog_is_post($page) || $page->intendedTemplate()->name() === 'about' ? blog_summary($page) : '';
    return $summary === '' ? BLOG_SITE['description'] : blog_truncate(ltrim(blog_plain($summary)));

/** The picture for link previews: the cover, on the home page that of the featured photo. */
function blog_share_cover(Page $page): ?File
{
    return ($page->isHomePage() ? blog_picks()->first() : $page)?->cover()->toFile();
}

/** Hugo's .Lastmod: About's date by hand, else the time of the page's content file. */
function blog_modified(Page $page): int
{
    return $page->lastmod()->isNotEmpty() ? $page->lastmod()->toDate() : $page->modified();
}

/** JSON for a script tag: "<" escaped, so it cannot close the tag. */
function blog_json(array $data): string
{
    return json_encode($data, JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE | JSON_HEX_TAG | JSON_PRETTY_PRINT);
}

/** The CSS of the site in one piece, in Hugo's order (head/css.html). */
function blog_css(): string
{
    $css = '';
    foreach (['fonts', 'tokens', 'base', 'page', 'exif', 'home', 'article', 'archive'] as $name) {
        $css .= F::read(kirby()->root('assets') . "/css/$name.css");
    }
    return $css;
}

/** URL of a file under assets/ with its time: a changed file gets a new URL. */
function blog_asset(string $path): string
{
    return url('assets/' . $path) . '?v=' . filemtime(kirby()->root('assets') . '/' . $path);

/** The name under which a cover moves between pages (vt-name.html). */

function blog_wide(File $file, int $width): FileVersion|File

    return $file->thumb(['width' => $width, 'format' => 'webp', 'quality' => 80]);

 * Width and height of blog_wide(), from the original: a page never has to
 * create a thumbnail to know its size. Kirby, unlike Hugo, never enlarges.
 */
function blog_wide_size(File $file, int $width): array
{
    $w = min($width, (int)$file->width());
    return [$w, $file->width() > 0 ? (int)round($file->height() * $w / $file->width()) : 0];
}

/** Hugo's Fill "NxN Smart webp qQ": a square from the middle, or from the focus point set in the Panel. */
function blog_square(File $file, int $edge, int $quality): FileVersion|File
{
    return $file->thumb(['width' => $edge, 'height' => $edge, 'crop' => true, 'format' => 'webp', 'quality' => $quality]);
}
```

```php
use Kirby\Cms\Page;
use Kirby\Text\KirbyTag;

/**
 * The KirbyText tags of a post. (image:) draws what Hugo's img shortcode
 * drew, (map:) what the map shortcode drew. Both stay one HTML block
 * without blank lines, so Markdown leaves them as they are.
 */

/**
 * The EXIF rows of an image as layouts/_partials/exif.html wrote them:
 * label => value, only the values the file has.
 */
function blog_exif_rows(File $file): array
{
    $value = fn (string $key) => trim((string)$file->content()->get($key)->value());
    $exposure = '';
    if (($shutter = $value('shutter')) !== '') {
        $exposure = str_starts_with($shutter, '1/') ? $shutter . 's' : sprintf('%.1fs', (float)$shutter);
    }
    if (($iso = $value('iso')) !== '') {
        $exposure = $exposure === '' ? "ISO $iso" : "$exposure · ISO $iso";
    }
    $aperture = $value('aperture');
    if ($aperture !== '') {
        $f = (float)$aperture;
        $aperture = floor($f) === $f ? sprintf('ƒ/%.0f', $f) : sprintf('ƒ/%.1f', $f);
    }
    return array_filter([
        'Camera' => $value('camera'),
        'Lens' => $value('lens'),
        'Focal length' => $value('focal') === '' ? '' : sprintf('%.0fmm', (float)$value('focal')),
        'Aperture' => $aperture,
        'Exposure' => $exposure,
    ], fn ($v) => $v !== '');
}

/** The (image:) tag. With imgclass it is a Markdown image, as ![alt](file){class="..."} was in Hugo. */
function blog_image_tag(KirbyTag $tag): string
{
    $file = $tag->file($tag->value);
    if ($file === null) {
        return '';
    }
    if ($tag->imgclass) {
        return '<img src="' . esc($file->url()) . '" alt="' . $file->alt()->esc() . '" class="' . esc($tag->imgclass) . '">';
    }
    return snippet('figure', ['file' => $file, 'page' => $tag->parent()], true);
}

/** The (map:) tag: points as numbers, the route inlined, as the Hugo shortcode. */
function blog_map_tag(KirbyTag $tag): string
{
    $page = $tag->parent();
    if (!$page instanceof Page) {
        return '';
    }
    $points = [];
    foreach ($page->mappoints()->toStructure() as $point) {
        $points[] = ['label' => $point->label()->value(), 'lat' => (float)$point->lat()->value(), 'lon' => (float)$point->lon()->value()];
    }
    $route = $page->route()->toFile()?->read() ?? '';
    return '<div class="map"' . ($page->mapzoom()->toBool() ? ' data-zoomable="true"' : '')
        . ' data-points="' . htmlspecialchars(json_encode($points, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_HEX_TAG | JSON_HEX_AMP), ENT_QUOTES) . '">'
        . ($route === '' ? '' : '<script type="application/json">' . $route . '</script>')
        . "\n</div>";
}
```

```php
/**
 * Posts that hold every word of $query in title, intro, text or the alt
 * text of an image, newest first, at most 40. KirbyText tags and link
 * targets do not count: a file name or URL would match almost anything.
 */
function blog_search(string $query): Pages
{
    $words = preg_split('/\s+/u', mb_strtolower(trim($query)), -1, PREG_SPLIT_NO_EMPTY);
    if ($words === []) {
        return new Pages([]);
    }
    return blog_posts()->filter(function (Page $post) use ($words) {
        $text = $post->title()->value() . ' ' . $post->intro()->value() . ' ' . $post->text()->value();
        $text = preg_replace(['/\([a-z]+:[^)]*\)/', '/\]\([^)]*\)/'], [' ', ']'], $text);
        $text = mb_strtolower($text . ' ' . implode(' ', $post->images()->pluck('alt')));
        foreach ($words as $word) {
            if (!str_contains($text, $word)) {
                return false;
            }
        }
        return true;
    })->limit(40);
}
```

```js
        "July", "August", "September", "October", "November", "December"
    ];

    var input = document.querySelector("[data-search-input]");
    var output = document.querySelector("[data-search-results]");
    if (!input || !output) return;

    var form = input.form;
    if (form) {
        form.addEventListener("submit", function (event) {
            event.preventDefault();
        });
    }

    function load(term) {
        return fetch("/search.json?q=" + encodeURIComponent(term))
            .then(function (response) {
                return response.ok ? response.json() : null;
            })
            .catch(function () {
                return null;
            });
    }

    function bar(label, count) {
        var heading = document.createElement("h2");
        heading.className = "archive-month stream-title";

        var name = document.createElement("span");
        name.textContent = label;

        var total = document.createElement("span");
        total.textContent = count;

        heading.appendChild(name);
        heading.appendChild(total);
        return heading;
    }

    function row(result) {
        var item = document.createElement("li");
        item.className = "archive-item";

        var day = document.createElement("span");
        day.className = "archive-day";

        var stamp = document.createElement("time");
        stamp.dateTime = result.date;
        stamp.textContent = String(Number(result.date.slice(8, 10)));
        day.appendChild(stamp);

        var title = document.createElement("a");
        title.className = "archive-title";
        title.href = result.url;
        title.textContent = result.title;

        item.appendChild(day);
        item.appendChild(title);

        if (result.thumb) {
            var frame = document.createElement("span");
            frame.className = "thumb";

            var image = document.createElement("img");
            image.src = result.thumb;
            if (result.thumb2x) {
                image.srcset = result.thumb + " 1x, " + result.thumb2x + " 2x";
            }
            image.width = 48;
            image.height = 48;
            image.alt = "";
            image.loading = "lazy";
            image.decoding = "async";

            frame.appendChild(image);
            item.appendChild(frame);
        }

        return item;
    }

    function render(results) {
        var next = document.createDocumentFragment();

        if (!results.length) {
            next.appendChild(bar("Nothing found", 0));
            output.textContent = "";
            output.appendChild(next);
            return;
        }

        var month = "";
        var list = null;

        results.forEach(function (result) {
            if (result.date.slice(0, 7) !== month) {
                month = result.date.slice(0, 7);

                var span = results.filter(function (other) {
                    return other.date.slice(0, 7) === month;
                }).length;

                var label = MONTHS[Number(result.date.slice(5, 7)) - 1] + " " + result.date.slice(0, 4);
                next.appendChild(bar(label, span));

                list = document.createElement("ul");
                list.className = "archive-list";
                next.appendChild(list);
            }

            list.appendChild(row(result));
        });

        output.textContent = "";
        output.appendChild(next);
    }

    // Der Suchbegriff steht in der Adresse, damit ein Neuladen ihn behält und
    // ein Treffer sich verlinken lässt. replaceState statt pushState, sonst
    // füllt jede getippte Zeichenfolge den Verlauf.
    function remember(term) {
        var next = term ? location.pathname + "?q=" + encodeURIComponent(term) : location.pathname;
        if (location.pathname + location.search !== next) {
            history.replaceState(null, "", next);
        }
    }

    function run() {
        var term = input.value.trim();
        remember(term);

        if (form) form.classList.toggle("has-term", !!input.value);

        if (!term) {
            output.textContent = "";
            return;
        }

        load(term).then(function (results) {
            if (input.value.trim() !== term) return;

            if (!results) {
                output.textContent = "";
                output.appendChild(bar("Search unavailable", 0));
                return;
            }

            render(results);
        });
    }

    input.addEventListener("input", run);

    if (form) form.classList.toggle("has-term", !!input.value);

    var opening = new URLSearchParams(location.search).get("q");
    if (opening) {
        input.value = opening;
        run();
    }
});
```

```php
<?php

use Kirby\Cms\Page;
use Kirby\Toolkit\Xml;

/**
 * The files for machines, from the content: the feed as Hugo's
 * home.rss.xml, the sitemap as sitemap.xml, robots.txt and llms.txt.
 */

/** The date format of RSS. */
const BLOG_RSS_DATE = 'D, d M Y H:i:s O';

/** The text of the feed, newest post first. */
function blog_rss(): string
{
    $site = site();
    $posts = blog_posts();
    $home = $site->url() . '/';
    $xml = '<?xml version="1.0" encoding="utf-8" standalone="yes"?>' . "\n"
        . '<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom">' . "\n"
        . "  <channel>\n"
        . '    <title>' . Xml::encode($site->title()->value()) . "</title>\n"
        . "    <link>$home</link>\n"
        . '    <description>' . Xml::encode(BLOG_SITE['description']) . "</description>\n"
        . "    <generator>Kirby</generator>\n"
        . "    <language>en-us</language>\n"
        . '    <lastBuildDate>' . ($posts->first()?->date()->toDate(BLOG_RSS_DATE) ?? '') . "</lastBuildDate>\n"
        . "    <atom:link href=\"{$home}index.xml\" rel=\"self\" type=\"application/rss+xml\" />\n";
    foreach ($posts as $post) {
        $link = $post->url() . '?source=rss';
        $xml .= "    <item>\n"
            . '      <title>' . Xml::encode($post->title()->value()) . "</title>\n"
            . "      <link>$link</link>\n"
            . '      <pubDate>' . $post->date()->toDate(BLOG_RSS_DATE) . "</pubDate>\n"
            . "      <guid isPermaLink=\"true\">$link</guid>\n"
            . '      <description><![CDATA[' . blog_rss_description($post, $link) . "]]></description>\n"
            . "    </item>\n";
    }
    return $xml . "  </channel>\n</rss>\n";
}

/** Cover, summary and the number of words after it, as home.rss.xml wrote them. */
function blog_rss_description(Page $post, string $link): string
{
    $html = '';
    if ($cover = $post->cover()->toFile()) {
        $w = (int)$cover->width();
        $h = (int)$cover->height();
        $scale = min(1, 768 / max($w, $h, 1));
        $html .= '<img src="' . $cover->thumb(['width' => 768, 'height' => 768, 'format' => 'webp', 'quality' => 80])->url()
            . '" width="' . (int)round($w * $scale) . '" height="' . (int)round($h * $scale)
            . '" alt="' . esc($post->title()->value() . ' cover image') . '" />';
    }
    $summary = blog_summary($post);
    $more = blog_words(blog_content($post)) - blog_words($summary);
    $html .= '<p>' . esc(html_entity_decode(blog_plain($summary), ENT_QUOTES | ENT_HTML5, 'UTF-8'));
    if ($more > 0) {
        $html .= ' (<a href="' . $link . '" title="Continue reading ' . esc($post->title()->value()) . '">' . $more . ' more words</a>)';
    }
    return $html . '</p>';
}

/** The home page and every post, each with its time and its cover. */
function blog_sitemap(): string
{
    $posts = blog_posts();
    $xml = '<?xml version="1.0" encoding="utf-8" standalone="yes"?>' . "\n"
        . '<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"' . "\n"
        . '  xmlns:image="http://www.google.com/schemas/sitemap-image/1.1">' . "\n";
    $newest = $posts->first() ? blog_modified($posts->first()) : null;
    $xml .= '  <url>' . "\n" . '    <loc>' . site()->url() . "/</loc>\n"
        . ($newest ? '    <lastmod>' . date('c', $newest) . "</lastmod>\n" : '') . "  </url>\n";
    foreach ($posts as $post) {
        $xml .= "  <url>\n    <loc>" . $post->url() . "</loc>\n"
            . '    <lastmod>' . date('c', blog_modified($post)) . "</lastmod>\n";
        // The cover as image entry, in the size the page shows.
        if ($cover = $post->cover()->toFile()) {
            $xml .= "    <image:image>\n      <image:loc>" . blog_wide($cover, 1600)->url() . "</image:loc>\n    </image:image>\n";
        }
        $xml .= "  </url>\n";
    }
    return $xml . "</urlset>\n";
}

/** Until the site is public (env.php: 'public' => true) search engines stay away. */
function blog_robots(): string
{
    return option('public') === true
        ? "User-agent: *\nAllow: /\n\nSitemap: " . url('sitemap.xml') . "\n"
        : "User-agent: *\nDisallow: /\n";
}

/**
 * Summary for language models (llmstxt.org): the introduction from
 * Website › Beiträge, then essays and notes with their summary, then
 * the pages of the site.
 */
function blog_llms(): string
{
    $site = site();
    $lines = ['# ' . $site->title()->value(), '', trim((string)$site->llms()->value())];
    foreach (['essays' => 'Essays', 'notes' => 'Notes'] as $section => $heading) {
        $posts = blog_posts()->filter(fn (Page $p) => $p->parent()->id() === $section);
        if ($posts->isNotEmpty()) {
            array_push($lines, '', "## $heading", '');
        }
        foreach ($posts as $post) {
            $summary = html_entity_decode(trim(preg_replace('/\s+/u', ' ', blog_description($post))), ENT_QUOTES | ENT_HTML5, 'UTF-8');
            $lines[] = '- [' . $post->title()->value() . '](' . $post->url() . '): ' . $summary;
        }
    }
    $url = $site->url();
    array_push($lines, '', '## Site', '',
        "- [Homepage]($url/)",
        "- [Archive]($url/archive/): All posts by month, filterable by type (photos, trips, notes, essays).",
        "- [About]($url/about/): Bio, full project list, blogroll, site statistics.",
        "- [Feed]($url/index.xml)",
        "- [Sitemap]($url/sitemap.xml)",
    );
    return implode("\n", $lines) . "\n";
}
```

```php
<?php

use Kirby\Cms\Page;
use Kirby\Cms\Response;

/**
 * URLs as Hugo had them: a post at /YYYY-MM-DD-slug/, every other page at
 * its path with a slash at the end, the home page at /.
 */
class BlogPage extends Page
{
    public function url($options = null): string
    {
        if ($options !== null) {
            return parent::url($options);
        }
        $base = $this->kirby()->url('base');
        if ($this->isHomePage()) {
            return $base . '/';
        }
        if (blog_is_post($this)) {
            return $base . blog_post_path($this);
        }
        return $base . '/' . $this->uri() . '/';
    }
}

/** The path of a post, /YYYY-MM-DD-slug/, with another slug if given. */
function blog_post_path(Page $post, ?string $slug = null): string
{
    return '/' . $post->date()->toDate('Y-m-d') . '-' . ($slug ?? $post->slug()) . '/';
}

/**
 * The post at /YYYY-MM-DD-slug/, or null. A draft only for the Panel or
 * with its preview token, as Kirby resolves drafts.
 */
function blog_post(string $date, string $slug): ?Page
{
    foreach (BLOG_SECTIONS as $section) {
        $post = page($section)?->childrenAndDrafts()->find($slug);
        if ($post === null || $post->date()->toDate('Y-m-d') !== $date) {
            continue;
        }
        if ($post->isDraft() && !(kirby()->user() && $post->isAccessible()) && $post->renderVersionFromRequest() === null) {
            return null;
        }
        return $post;
    }
    return null;
}

/**
 * Answers a path before Kirby does, or null for Kirby's own routes:
 * a post, an original image at its Hugo URL, every page only at its URL
 * with the slash at the end, as Apache served Hugo's folders.
 */
function blog_route(string $path): Page|Response|null
{
    if (preg_match('!^(\d{4}-\d{2}-\d{2})-([a-z0-9-]+)(?:/([^/]+))?$!', $path, $m)) {
        $post = blog_post($m[1], $m[2]);
        if ($post !== null && isset($m[3])) {
            $file = $post->file($m[3]);
            return $file ? Response::redirect($file->url(), 301) : null;
        }
        return $post ? blog_canonical($post, $path) : null;
    }
    // A path with an extension is a content representation (search.json): Kirby's.
    $page = $path === '' || str_contains(basename($path), '.') ? null : kirby()->site()->find($path);
    return $page && !$page->isErrorPage() ? blog_canonical($page, $path) : null;
}

/**
 * The page, if $path is its address; else a redirect there. The router
 * drops the slash at the end, so it comes from the request itself.
 */
function blog_canonical(Page $page, string $path): Page|Response
{
    $kirby = $page->kirby();
    $url = $page->url();
    $own = (string)parse_url($url, PHP_URL_PATH);
    $request = (string)parse_url((string)$kirby->environment()->get('REQUEST_URI'), PHP_URL_PATH);
    if (trim($own, '/') === $path && ($request === '' || $request === $own)) {
        return $page;
    }
    $query = $kirby->request()->query()->toString();
    return Response::redirect($url . ($query === '' ? '' : "?$query"), 301);
}
```

```php
/**
 * Writes data/redirects.yaml as the redirects of the site
 * (content/.redirects.json) with the fixed time. Returns their number.
 */
function hugo_import_redirects(string $yaml, string $content): int
{
    // Symfony, not Kirby's default Spyc: Spyc cuts "#things-i-built" off as a comment.
    $redirects = Symfony\Component\Yaml\Yaml::parseFile($yaml);
    foreach ($redirects as $redirect) {
        if (!isset($redirect['from'], $redirect['to']) || array_diff(array_keys($redirect), HUGO_REDIRECT_KEYS)) {
            throw new RuntimeException("$yaml: unknown redirect " . json_encode($redirect));
        }
    }
    $file = "$content/.redirects.json";
    file_put_contents($file, json_encode($redirects, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE) . "\n");
    touch($file, HUGO_FIXED_TIME);
    touch($content, HUGO_FIXED_TIME);
    return count($redirects);
}
```

```php
    foreach (blog_redirects() as $redirect) {
```

```php
/**
 * Hook after a slug or date change: the old path of a published post
 * leads to the new one. Redirects to the old URL move on to the new one,
 * so there is never more than one step, and none starts at the new URL.
 * The feed keeps the post's GUID: the new redirect carries rss: keep,
 * unless a redirect to the old URL carries it already.
 */
function blog_redirect_moved(Page $post, string $from): void
{
    $to = blog_post_path($post);
    if (!blog_is_post($post) || !$post->isListed() || $from === $to) {
        return;
    }
    $guid = false;
    $redirects = [];
    foreach (blog_redirects() as $redirect) {
        if ($redirect['to'] === $from) {
            $guid = $guid || ($redirect['rss'] ?? '') === 'keep';
            $redirect['to'] = $to;
        }
        if ($redirect['from'] !== $to) {
            $redirects[] = $redirect;
        }
    }
    $redirects[] = ['from' => $from, 'to' => $to] + ($guid ? [] : ['rss' => 'keep']);
    blog_redirects_write($redirects);
}
```

```php
<?php

/**
 * Pop's visits (var/data.db on the server, SQLite) as daily totals of
 * "Besucher" (content/.analytics), once, before Pop goes. Pop counted a
 * browser on a page at most once in 30 minutes; a row is one such view.
 * Only rows of this site count, an old URL counts for the page its
 * redirect leads to. A day Kirby has counted already stays as it is.
 */

const POP_SITE = 'https://sven.eisenschmidt.website';

/** The Kirby page id of a URL Pop counted, or null. */
function pop_page_id(string $url): ?string
{
    if ($url !== POP_SITE && !str_starts_with($url, POP_SITE . '/')) {
        return null;
    }
    $path = (string)parse_url($url, PHP_URL_PATH);
    $path = trim((string)parse_url(blog_redirect_to($path) ?? $path, PHP_URL_PATH), '/');
    if ($path === '') {
        return site()->homePage()?->id();
    }
    if (preg_match('!^(\d{4}-\d{2}-\d{2})-([a-z0-9-]+)$!', $path, $m)) {
        return blog_post($m[1], $m[2])?->id();
    }
    return site()->find($path)?->id();
}

/**
 * Adds the days of the database $db that "Besucher" does not have.
 * Returns the number of rows, of days written and kept, and the URLs
 * without a page with their rows.
 */
function pop_import(string $db): array
{
    $pdo = new PDO('sqlite:' . $db, null, null, [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]);
    $ids = [];
    $days = [];
    $unknown = [];
    $rows = 0;
    foreach ($pdo->query('SELECT page_id, fingerprint, visited_at FROM visits ORDER BY visited_at') as $row) {
        $rows++;
        $id = $ids[$row['page_id']] ??= pop_page_id($row['page_id']) ?? false;
        if ($id === false) {
            $unknown[$row['page_id']] = ($unknown[$row['page_id']] ?? 0) + 1;
            continue;
        }
        $date = date('Y-m-d', (int)$row['visited_at']);
        $days[$date]['visitors'][$row['fingerprint']] = true;
        $days[$date]['views'] = ($days[$date]['views'] ?? 0) + 1;
        $days[$date]['pages'][$id][$row['fingerprint']] = true;
    }

    $months = [];
    $written = 0;
    foreach ($days as $date => $day) {
        $month = substr($date, 0, 7);
        $months[$month] ??= blog_analytics_month($month, true);
        if (isset($months[$month][$date])) {
            continue;
        }
        $months[$month][$date] = [
            'visits' => count($day['visitors']),
            'views' => $day['views'],
            'pages' => array_map('count', $day['pages']),
            'referrers' => [],
        ];
        $written++;
    }
    foreach ($months as $month => $data) {
        ksort($data);
        blog_analytics_write(blog_analytics_dir() . "/$month.json", $data);
    }
    arsort($unknown);
    return ['rows' => $rows, 'days' => $written, 'kept' => count($days) - $written, 'unknown' => $unknown];
}
```

```php
 * Compares every Kirby page with the page Hugo built (public/), after a
 * normalisation that leaves out what is meant to differ:
 * - white space between tags and runs of white space,
 * - how HTML is written (quotes, entities, "/>"): both sides go through
 *   PHP's HTML5 parser and come out the same way,
 * - Hugo's generator tag, Pop (script, preconnect) and Pagefind attributes,
 * - the content of inline CSS and JS (Hugo minified it): each script
 *   becomes [js:name], the style [css],
 * - URLs: the host, image URLs (Hugo's _hu_ names, Kirby's media URLs)
 *   as [img:name] and [file:name], asset URLs as [asset:name],
 * - JSON (JSON-LD, map points) decoded and encoded again.

 * and prints each page that differs with the elements that differ.

 */

/** A URL as both sides can agree on it. */
function parity_url(string $url): string
{
    // Hugo wrote %C3%9C where Kirby writes Ü: the same URL.
    $url = rawurldecode(str_starts_with($url, PARITY_HOST) ? substr($url, strlen(PARITY_HOST)) : $url);
    $path = (string)parse_url($url, PHP_URL_PATH);
    $name = strtolower(basename($path));
    // Hugo: /<post>/<name>_hu_<hash>.webp; Kirby: /media/pages/<id>/<hash>/<name>-<options>.webp
    if (preg_match('/^(.+)_hu_[0-9a-f]+\.\w+$/', $name, $m) || (str_starts_with($path, '/media/') && preg_match('/^(.+?)-\d*x\d*(-[a-z0-9-]+)?\.\w+$/', $name, $m))) {
        return '[img:' . $m[1] . ']';
    }
    if (preg_match('/\.(jpe?g|png|webp|gif)$/', $name)) {
        return '[file:' . $name . ']';
    }
    // Hugo: /leaflet/leaflet.min.<hash>.css; Kirby: /assets/leaflet/leaflet.css?v=<time>
    if (preg_match('!^(/assets)?/(js|leaflet)/(\w+)(\.min)?(\.[0-9a-f]{64})?\.(css|js)$!', $path, $m)) {
        return '[asset:' . $m[3] . '.' . $m[6] . ']';
    }
    return $url;
}

/** The page as one string, one tag per line. */
function parity_normalise(string $html): string
{
    $html = preg_replace([
        '!<meta name="generator"[^>]*>!',
        '!<link rel="(dns-prefetch|preconnect)" href="https://pop\.[^>]*>!',
        '!<script src="https://pop\.[^>]*></script>!',
        '!<script defer>\s*document\.addEventListener\("DOMContentLoaded", function \(\) \{\s*if \(window\.location\.hostname.*?</script>!s',
        '! data-pagefind-(body|ignore|meta="[^"]*")!',
    ], '', $html);
    $doc = Dom\HTMLDocument::createFromString($html, LIBXML_NOERROR, 'UTF-8');
    foreach ($doc->querySelectorAll('style') as $style) {
        $style->textContent = '[css]';
    }
    foreach ($doc->querySelectorAll('script') as $script) {
        $type = $script->getAttribute('type');
        if ($script->hasAttribute('src')) {
            continue;
        }
        if ($type === 'application/ld+json' || $type === 'application/json') {
            $data = json_decode($script->textContent, true);
            if (is_array($data)) {
                array_walk_recursive($data, function (&$value) {
                    $value = is_string($value) && str_starts_with($value, 'http') ? parity_url($value) : $value;
                });
            }
            $script->textContent = $data === null ? trim($script->textContent) : json_encode($data, JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE);
            continue;
        }
        $name = 'unknown';
        foreach (PARITY_SCRIPTS as $marker => $js) {
            if (str_contains($script->textContent, $marker)) {
                $name = $js;
                break;
            }
        }
        $script->textContent = "[js:$name]";
    }
    foreach ($doc->querySelectorAll('[src], [href], [srcset], meta[content^="http"], [data-points]') as $el) {
        foreach (['src', 'href', 'content'] as $attr) {
            if ($el->hasAttribute($attr)) {
                $el->setAttribute($attr, parity_url($el->getAttribute($attr)));
            }
        }
        if ($el->hasAttribute('srcset')) {
            $el->setAttribute('srcset', implode(', ', array_map(function ($item) {
                [$url, $size] = preg_split('/\s+/', trim($item)) + [1 => ''];
                return parity_url($url) . ' ' . $size;
            }, explode(',', $el->getAttribute('srcset')))));
        }
        if ($el->hasAttribute('data-points')) {
            $el->setAttribute('data-points', json_encode(json_decode($el->getAttribute('data-points'), true), JSON_UNESCAPED_UNICODE));
        }
    }
    // Hugo put runs of images into a <p>, which the browser closes empty.
    foreach ($doc->querySelectorAll('p:empty') as $p) {
        $p->remove();
    }
    $out = $doc->saveHtml();
    $out = preg_replace(['/\s+/u', '/\s*(<[^>]+>)\s*/u'], [' ', '$1'], $out);
    return preg_replace('/(?<!^)(<[a-z])/', "\n$1", $out);
}

    foreach ($doc->url as $url) {
        $image = $url->children('http://www.google.com/schemas/sitemap-image/1.1')->image;

    }
    return $urls;
}
```

## Was Phase 5 wissen muss

- **Seiten-Cache beim Deploy:** Der Cache sieht keine Änderung am Code. Der Deploy leert ihn nach dem Hochladen unter der Sperre, wie Luisas `bin/clear-cache.php` mit dem Typ `BlogFileCache`. Ohne das zeigt der Server altes HTML mit alten `?v=` der Assets.
- **Erster Abruf:** Kirby rechnet Vorschauen beim ersten Abruf eines Bildes. Nach dem Umschalten einmal jede Seite und jedes Bild abrufen (Tabelle „Rückbau“, Zeile Bild-Cache).
- **Pop-Import:** `php85 bin/pop-import.php <kopie von var/data.db>` auf dem Server, oder lokal gegen eine Kopie des Zustands vor dem Restore. Nur einmal, vor dem Abschalten von Pop. Danach Rohdaten mit Fingerprints löschen.
- **`env.php`:** `'public' => true` erst beim Umschalten, sonst sperrt `robots.txt` alles. `'url' => 'https://sven.eisenschmidt.website'`, sonst nennen Feed, Sitemap und `canonical` den Host der Anfrage.
- **Löschen nach dem Hugo-Rückweg:** `assets/`, `static/`, `layouts/`, `scripts/check-urls.sh`, `scripts/to-srgb.sh`, `data/redirects.yaml` (die Weiterleitungen leben dann in `content/.redirects.json`, die Datei ist nur noch Geschichte), Pagefind im Deploy, `hugo.toml`, `archetypes/`.
- **About von Hand:** Der Abschnitt „About this Website“ nennt Hugo und Pop. Sven ändert ihn im Panel, sobald Kirby live ist.
- **Objektiv bei 5 Fotos:** unverändert, nach dem letzten Import im Panel eintragen.
- **Bild-Blueprint:** Bekommt `files/image.yml` je `create:`-Optionen, liest der EXIF-Hook vor dem Umrechnen (Notiz „Phase 3, Bild-Blueprint“). Dieser Plan setzt keine.
